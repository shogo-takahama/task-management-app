# 1. 基本アーキテクチャおよび技術スタックの選定

* **ステータス:** 承認済み (Accepted)
* **日付:** 2026-10-20
* **意思決定者:** 自分（個人開発）

---

## 1. コンテキストと問題提起 (Context & Problem)

レガシー（Java + SAStruts2 + HTML5）の開発実務経験を活かし、モダンな開発アプローチを取り入れたポートフォリオを構築したい。

---

## 2. 検討した選択肢 (Considered Options)

1. **構成案 A (フロントエンド、バックエンドの一体型):** Next.js / Nuxt などをベースにした一体型の構成
2. **構成案 B (フロントエンド、バックエンドの分離型):** Java (Spring Boot) + React (TypeScript) による分離型の構成

---

## 3. 意思決定 (Decision)

**構成案 B (Spring Boot 4 + React 19 + PostgreSQL + JWT認証)** を採用する。

### 採用理由 (Rationale):

中規模以上の現場では分離型であることが多いため。
Java/Spring Boot による REST API 設計、例外処理、認証・認可基盤の構築スキルをアピールするため。

---

## 4. トレードオフと結果 (Consequences)

### メリット (Positive):
- フロントエンド（React）とバックエンド（Spring Boot）のコードやデプロイ環境を完全に切り離して管理できる。
- JWT（ステートレス認証）を採用することでサーバー側にセッション状態を持たせず、今後の機能拡張やサーバー構成変更に柔軟に対応できる。
- ADR や Swagger UI を整備することで、設計意図や API 仕様を第三者にわかりやすく共有できる。

### デメリット・課題 (Negative / Trade-offs):
- 一体型に比べ、リポジトリの管理や CORS 設定、認証設計のコストが高くなる。
- **対策:** Docker Compose や CI/CD (GitHub Actions) を初期段階で導入し、開発環境およびテストのコストを低減させる。
